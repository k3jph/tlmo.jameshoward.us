# Teaching and Learning Mathematics Online

Official companion site for *Teaching and Learning Mathematics Online*, edited by James P. Howard, II and John F. Beyers.

This repository contains the static Astro site for **tlmo.jameshoward.us**, covering both the 2020 first edition and the 2025 second edition.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The site is designed for GitHub Pages and deploys through GitHub Actions.
